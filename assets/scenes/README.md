# Scenes

Background photos for the example creatives, one per angle and profile.

They were made once with an image model (`gpt-image-1-mini`) from a one-line scene description, with
no text and no logo in the prompt. They are example images for this repository. They are not
creatives from my job, and they show no real person or place.

The pipeline only reads these files. It never calls an image model. The logo, headline, button and
disclaimer are placed on top by `pipeline/svg.py`.
